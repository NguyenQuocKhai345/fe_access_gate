# Contributing

Thanks for contributing to this template.

## Development setup

1. Fork and clone the repository.
2. Install dependencies: `npm install`
3. Start the app: `npm run dev`

## Before opening a PR

1. Run `npm run lint`
2. Run `npm run type-check`
3. Ensure your changes include docs updates when behavior changes.

## Commit conventions

- Keep commits focused and small.
- Use clear commit messages with an imperative title.
- Make sure pre-commit hooks pass locally.

## Pull request checklist

- Explain what changed and why.
- Include screenshots or short videos for UI changes.
- Link related issues when relevant.
